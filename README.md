A program that writes one funny out-of-office auto-reply to `/output/entry.txt`, for the make.fun competition [The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf).

## Run it

```sh
python3 main.py
```

It writes the out-of-office reply below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The out-of-office reply is 104 characters, inside the 1 to 140 gate.

> I am out of office. Please direct all emergencies to my cactus. It is the only one here with boundaries.
